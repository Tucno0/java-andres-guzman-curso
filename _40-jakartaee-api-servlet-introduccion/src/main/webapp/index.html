Hola mundo Tomcat

Este es un ejemplo de una aplicación web Java EE desplegada en Tomcat.

  • Ir a parametro saludo GET (/webapp/parametros/url-get?saludo=Hola)
  • Ir a parametro saludo GET (/webapp/parametros/url-get?saludo=Hola&nombre=Juan)
  • Ir a parametro saludo GET (/webapp/parametros/url-get?nombre=Juan)
  • Ir a parametro saludo GET (/webapp/parametros/url-get?saludo=Hola&nombre=Juan&codigo=12345)
  • Ir a parametro saludo GET (/webapp/tarea1?nombre=Juan&apellido=Perez)
